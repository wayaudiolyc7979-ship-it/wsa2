오라리제이션 · TF 줌/팬 · 표준 정합

측정을 귀로 듣는 오라리제이션, TF 주파수축 줌/팬, 전체 코드 점검으로 정확도·안정성까지.

  • 다채널 채널 선택 — 격자 피커 (신규) — 입력 많은 인터페이스(예: 64채널)에서 채널을 화면 밖으로 넘치던 긴 목록 대신 번호 격자로. 64채널도 8×8 한 화면, 스크롤·드래그 없이 클릭 한 번 선택(채널 많을 때만 격자). 모든 드롭다운에 스크롤 안전망 추가
  • 스펙트럼 소스별 개별 시작/정지 (신규) — 각 입력 카드에 Start(전원 LED) 버튼. 마이크(소스)마다 따로 측정 on/off — 1번만 켜고 2번은 꺼두기 가능. 측정 중=LED 파랑 발광 / 꺼짐=흐린 링. 곡선 표시(✓)와 별개. 전역 Start 버튼은 없애고 S 키로 전부 시작/정지
  • 🎧 오라리제이션 (신규) — 측정한 임펄스 응답(IR)에 음악을 통과시켜 그 공연장·그 스피커로 재생된 것처럼 헤드폰으로 듣기. 원음(Dry) ↔ 공간(Room) 버튼으로 A/B, 라이브 IR·캡처 중 선택. Transfer Function 툴바 🎧 버튼
  • Transfer Function 주파수축 줌/팬 (신규) — Magnitude·Phase를 특정 대역으로 확대: 휠(커서 기준) · 드래그(박스 줌) · Shift+드래그(이동) · Cmd +/− · 더블클릭/Cmd 0(리셋). 매그·위상·코히런스가 같은 축으로 연동
  • 🎚️ TF 라이브 멀티마이크 평균 — 공간 평균 (신규) — 마이크를 객석 여러 위치에 두고 동시 측정 시 그 구역의 평균 주파수 응답을 실시간 곡선(AVG)으로. TF 툴바 Σ 버튼 팝업에서 켜고(평소 숨김), 팝업 마이크 체크리스트에서 평균 대상 선택(카드 avg 토글과 동기). 위치마다 거리 달라도 크기(파워)만 평균해 위상 영향 없이 평균 톤 밸런스. 평균만으로 개별 숨기고 AVG만. 정지 곡선을 합치는 캡처 평균과 달리 측정 중 실시간 갱신
  • 캡처 불러오기 (신규) — 내보낸 캡처 CSV를 다시 불러와 복원. Magnitude·Phase·Coherence는 물론 임펄스 응답(IR)까지 되살려 표시. 캡처 드로어 ↑ 버튼
  • dB 세로축 수동 고정 (신규) — 세로축 상·하한을 정확한 dB 값으로 직접 입력해 고정. 툴바 dB 버튼(평소 Auto)을 눌러 상·하단 입력, 잠기면 버튼이 파란 +N/−N 표시. 측정값이 변해도 안 바뀜. 해제=대화상자 [자동] 또는 눈금 더블클릭. 스펙트럼·TF 공통, 재시작에도 유지
  • 세 탭 툴바 전면 리디자인 (프로 계측기 스타일) — Spectrum·TF·Stereo 상단 컨트롤 바를 하나의 새 디자인으로 통일. 둥근 버튼 나열 → 테두리 없는 컨트롤 + 직관 아이콘 + 활성만 파랑 강조(토글=LED 점) + 모노스페이스 숫자. 조작감 동일(값=클릭 드롭다운, hover 시 클릭영역 표시)
  • 상단 탭 바 정돈 — 탭을 아이콘+이름으로, 활성 탭은 이름 폭에 맞는 파란 밑줄로. 겹치던 가로줄 정리로 상단이 깔끔. 탭 아이콘도 뜻 명확(스펙트럼=막대·TF=비교·Stereo=음량)하게 겹침 없이 정리
  • 오른쪽 패널·마이크 카드·캡처 목록까지 같은 결로 — 정보 패널을 하나의 외곽 프레임 + 얇은 구분선으로(레벨 표시는 그대로), 마이크 카드는 큰 숫자 레벨로. 캡처 목록은 무거운 상자·체크박스를 걷어내고 배경 위에 곡선색 이름만 — 왼쪽 색 점을 눌러 표시/숨김 토글. 툴바·패널·목록 배경색 통일
  • 툴바 버튼 순서를 기능별로 정리 — 세 탭 모두 같은 성격 설정끼리 붙이고 실행 버튼(Reset·Capture 등)은 따로 모아 배치. 왼쪽→오른쪽 분석 → 표시 → 실행 흐름
  • 상단 브랜드 헤더도 같은 언어로 — 최상단 줄(테마·언어·프리셋·저장·삭제·Calibration)의 파란 필·테두리를 걷어내고 테두리 없는 컨트롤 + hover 배경으로. 캡처 + Grp 버튼도 동일
  • Transfer Function 오른쪽 패널도 N2로 — 신호 발생기·측정 카드를 앱 전체와 같은 결로. 신호 타입(Pink/White/Sine/Sweep/파일)을 드롭다운 하나로 합쳐 레벨과 한 줄에(5줄→3줄), 파란 필·회색 배경 제거→테두리 셀. 측정 카드는 스펙트럼과 똑같이 중립 테두리 + 색 스와치 + 색 점 눌러 측정 on/off
  • 스펙트럼 소스별 색 변경 — 카드마다 곡선 색 변경. 우클릭 → 색 변경…(또는 카드 선택 후 툴바 Color). 곡선·카드 표시(네모·점·번호)에 함께 반영, 재시작 유지
  • 캡처를 많이 쌓아도 매끄럽게 — 캡처가 수십·수백 개로 늘어도 추가·선택 시 멈칫하던 것을 근본 수정(개수 무관, 스펙트럼·TF 공통)
  • TF Reference·측정 미터 정렬 · 아이콘 전반 정제 — 레벨 바를 좌우로 나란히, 아이콘을 더 높은 해상도·둥근 꼭짓점으로
  • 스펙트럼 INPUT 카드 조작 통일 — 인라인 ✕ 삭제 버튼 제거, 삭제·이름 변경을 우클릭 메뉴로 통일(TF 측정 카드와 동일). 모든 카드 헤더가 같은 모양, 실수로 지우기 쉬운 ✕ 대신 의도적 우클릭으로만 삭제(이름 변경=우클릭·더블클릭)
  • 딜레이 적용 시 크기 응답이 즉시 올바른 레벨로 (Smaart 방식 시간정렬) — 이전엔 딜레이가 위상만 정렬하고 크기·코히런스는 어긋난 채였는데(특히 Adaptive 고역), 이제 FFT 이전 시간영역에서 정렬해 크기·코히런스도 딜레이 넣는 순간 올바른 레벨로 딱 잡힘
  • 세부 다듬기 — TF Magnitude/Phase에 줌·팬 조작 안내 툴팁, Group Delay 세로축 눈금 5ms 균일 정리, 오라리제이션 정지 버튼 툴팁
  • 마지막 탭 기억 — 앱을 다시 열면 마지막에 보던 탭(Spectrum/TF/Stereo)으로 시작, 레이아웃·설정도 함께 복원
  • TF 응답 대칭화 (Smaart식) — 크기 곡선이 올라갈 때·내려갈 때 같은 속도로 반응(비대칭 fast-release 제거). Response로 양방향 속도 조절, 값도 짧게(Fast 0.5초 … Stable 8초, 기본 Normal 2초)
  • 라우드니스(LUFS) 표준 정합 — 약 3 LU 상향 — 좌우 채널 합산 방식을 국제표준(ITU-R BS.1770)에 맞춰, 다른 표준 미터·방송 납품 기준(−23 LUFS 등)과 값이 일치
  • 우클릭 메뉴가 밝은 색으로 뜨던 문제 수정 — 카드 우클릭(이름 변경·삭제) 등 컨텍스트 메뉴·일부 툴팁이 밝은 회색/흰색으로 뜨던 것을, 앱 전체(팝아웃·대화상자 포함) 어두운 테마로 통일
  • 전체 코드 점검 안정화 — 로그 스케일 라이브 곡선 표시 회귀, 스펙트럼 단독 USB 자동복구, Stereo 오른쪽 채널 지정, 캡처·주파수축 확대 표시, 설정 저장 안정성 등 다수 수정
  • TF RTA 칸 빈 화면 · 눈금 잘림 정리 — 신호가 들어오는데 RTA(옥타브) 칸이 "Press Start"만 뜨던 문제, Phase/Mag/IR 맨 위 눈금이 카드 상단에 잘리던 것, IR 시간축 양끝 라벨 겹침 정리
  • 패널을 짧게 줄였을 때 축 글씨 겹침 수정 — 세로축 라벨이 서로 뭉치거나(Mag·Phase) IR 바닥 시간·거리 눈금이 카드 테두리에 겹치던 것 해결. 그리드는 유지하고 글씨만 자동으로 성기게 표시(스펙트럼·TF 공통)
  • 패널 제목 클릭영역 수정 · 제목 확대 — IR/Phase/Magnitude 제목(Magnitude + Coherence ▾)의 클릭 영역이 글씨 아래를 못 덮어 모서리를 눌러야 했던 것을 바로잡아 제목 어디를 눌러도 메뉴가 뜨게 하고, 제목 글씨도 조금 키움

SPL 미터 재디자인 · TF 측정 개선 · 안정성

SPL 미터·TF 화면을 새로 다듬고, 측정 정확도와 장시간 안정성을 손봤습니다.

  • SPL 미터 디자인 정비 — 카드 아래 신호등 색 번짐(초록·노랑·빨강)으로 상태를 한눈에, 값 색을 LEVEL 패널과 통일, 배경/카드 반전, Max 리셋을 카드별로, 타이틀바 아이콘(핀·기어) 정제
  • Transfer Function 3그래프 카드 분리 — Live IR · Phase · Magnitude+Coherence를 각각 떠 있는 둥근 카드로, 고유 색 제목(IR 청록/Phase 보라/Mag 파랑), 선택 시 SPECTRA 그라디언트 엣지
  • TF 화면 정리 · 자동 Y축 맞춤 · 하강 속도 2배 — 코히런스 기준선/% 눈금 제거(값은 커서 리드아웃)·블루 반투명 밴드, 측정 시작 시 첫 데이터 자동 맞춤, 신호 줄 때 곡선이 약 2배 빠르게 하강
  • 사이드바·값 색 정돈 — 섹션 헤더를 액센트 세로 바로 통일, A가중 소프트 블루·C가중 소프트 와인, SPL 미터 버튼 아이콘 "dB"
  • TF 팝아웃에서도 캡쳐 패널 · SPL 알람 창 정비(배경 통일 · LAeq/LCeq 적분 진행 바 + 리셋)
  • 라우드니스 장시간 멈춤 수정 — 수 시간 켜두면 느려지다 멈추던 문제 해결(적분·LRA를 블록 단위로, 부하 일정)
  • 측정 미터·분석 간헐 멈춤 수정 — 스윕→핑크 전환 후 미터·그래프가 빈 채 멈추던 CoreAudio 경합을 감지해 자동 재개(약 2초 복구)
  • 정밀 스윕(Farina) 정확성 다수 수정 — 스윕 후 위상 자동 0ms 정렬, 스윕↔핑크 레벨 일치(정규화 → 겹쳐 비교 가능), 1초·2초 결과 일치, IR 경계 테이퍼로 링잉 완화
  • 스윕 ↔ 핑크 전환 정리 — Play 시 측정 카드 자동 시작, 마이크 이동 후 딜레이 재적용, 핑크 미측정 해소
  • 미세 스무딩(1/48) 버벅임·끊김 수정 · 제너레이터 기본 소스 정리(항상 Pink 시작) · 삭제한 소스 카드 부활 수정 · COMPLIANCE 배지 안티앨리어싱

적응형 엔진 · 프리셋 · 다국어

라이브에 강한 새 TF 엔진, 세 탭 설정을 기억하는 프리셋, 한/영 전환, 라우드니스 화면 재정비.

  • TF Adaptive 엔진 (신규·기본) — 멀티레이트(적응 해상도) 라이브: 저역은 고해상도, 고역은 빠른 응답. 현장 튜닝(이동·EQ 조정)에 강함. Engine 셀렉터로 Single ↔ Adaptive
  • 정밀 스윕 (Farina ESS) — Sweep 1-shot 측정 → 무왜곡 TF + THD/SNR (정밀·THD는 스윕, 라이브는 Adaptive)
  • 응답 속도(Response) 컨트롤 — Fast · Quick · Normal · Smooth · Stable 한 단어로 직관 선택, 바꾸면 즉시 체감(곡선 30fps 보간)
  • 스펙트럼 빠른 상승·느린 하강 — 소리에 빠르게 반응해 올라오고 잔향처럼 천천히 내려오는 피크미터식 응답(Avg 컨트롤은 Response로 일원화)
  • 설정 자동 기억 + 이름 프리셋 (신규) — 세 탭 모든 컨트롤을 자동 저장·복원, 현장별 세팅을 이름 붙여 즉시 전환
  • 한국어 / 영어 전환 (신규) — 헤더 지구본 버튼으로 KO ↔ EN (첫 실행은 OS 언어). 한글 모드에선 툴팁·설정·우클릭 메뉴를 쉬운 한국어로
  • 라우드니스 화면 재정비 — PROGRAM LOUDNESS를 AVG | LIVE 2분할 동시 표기, 레이더 외곽 미터를 타겟 중심으로 재배치(타겟이 12시 중앙), 히스토리는 부드러운 60초 곡선, 벡터스코프·레이더 확대
  • 창 최대화 + 팝아웃 정비 — 헤더 더블클릭=최대화, 탭 별도 창을 다크 브랜드 헤더로 통일·툴바 접기
  • 라이트 모드 전체 정비 — 일부만 밝던 패널·미터·다이얼로그까지 모두 테마 반영

캡쳐를 한 손에

쌓인 캡쳐를 한 번에. 라이브 튜닝 디테일과 SPL 모니터링까지 키웠습니다.

  • 캡쳐 일괄 표시/숨김 + 그룹별 토글 — 패널 머리말 버튼으로 현재 탭·그룹을 한 번에
  • 리캡쳐(R) · 전체 삭제 · 위치 지정 — 색·이름은 그대로 곡선만 갱신, 새 캡쳐가 들어갈 그룹 지정
  • SPL 임계 알람 창 (신규) — 한계에 다가가면 초록 → 노랑 → 빨강 신호등으로 즉시 경고(독립 동작)
