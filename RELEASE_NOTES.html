v2.0.22026.09최신

정확도·안정성 보강 (빌드전 심층리뷰)

v2.0.1 배포 이후 전체 코드를 심층 재점검해 오래된 정확도·안정성 문제를 위험도순으로 바로잡은 유지보수 릴리스입니다. 동작·화면은 그대로.

  • 라우드니스 표준 추가 정합 — 게이팅·샘플레이트 — 통합 라우드니스의 게이팅 구간을 국제표준(BS.1770, 400ms·75% 겹침)에 정확히 맞추고, 44.1kHz·고배율(96/192kHz)에서 K-가중이 어긋나던 것도 수정. 특히 44.1kHz(CD 레이트) 저음 가중 오류를 바로잡아 모든 샘플레이트에서 규격에 맞는 값
  • 캡처 파일도 원자적 저장 — 저장된 캡처(스펙트럼·TF 곡선)도 저장 도중 앱이 꺼져도 파일이 깨지지 않도록 보강 — 저장 캡처가 통째로 사라질 위험 제거
  • 장시간 측정 자동복구 보강 — 마이크가 오래 뒤 멈추는 문제의 남은 경로 하나(장치는 인식되는데 콜백만 죽어 방치되던 드문 경우)도 같은 장치로 자동 재시작(Spectrum·TF 공통)
  • 탭 동시 사용 시작 안정성 — 한 인터페이스를 다른 탭이 이미 다른 샘플레이트로 쓸 때 Spectrum·Stereo 시작이 실패하던 것을, 먼저 연 쪽에 자동으로 맞춰 함께 켜지도록 개선
  • TF 종료 후 Spectrum 응답성 회복 · USB 재연결 감지·벡터스코프·유령 프레임 정리 — TF를 끈 뒤 지연이 안 내려가던 것, USB 재연결 폴링이 두 배로 돌던 것, 벡터스코프가 콜백 속도에 끌려 버벅이던 것(30fps 통일), 카드 정지 순간 곡선이 한 프레임 남던 것 정리
  • 한국어 UI 완성도 보강 — 한글 모드에서 영어로 남아있던 문구 30여 곳(오라제이션 다이얼로그·Stereo Loudness 상태 표시·일부 툴팁)을 번역(Auralization=오라제이션 표기)
  • 오래 켜둬도 가벼워졌습니다 — 장시간 성능 — 몇 시간씩 켜두면 점점 무거워지던 원인들을 걷어냈습니다. 라우드니스 적분 약 29배(8시간 기준, 메모리 18→2MB)·SPL LEQ 표시 약 69배(3시간 기준) 가속, 캡처가 수십 개여도 캡처 시 화면이 멈추지 않도록 저장을 백그라운드로(예전 50개=2초·100개=4초 정지), 측정 상시 CPU 20%→2%, 옥타브 막대 이중 그리기 제거(1/24에서 42% 절감)·TF 곡선 생성 5배. 측정값과 화면은 그대로
  • 정지 상태 "다시 캡처"가 기존 캡처를 지워버리던 문제 수정 — 측정이 멈춘 상태에서 재캡처하면 저장해둔 곡선이 −96dB 평평한 선으로 덮어써지고 그대로 저장되던 심각한 문제를 차단(아무것도 저장 안 됐는데 "✓ Captured"가 뜨던 것도 함께 수정)
  • 자동복구·정확성 보강 — 장시간 자동복구가 TF 별도 창·Stereo 탭에서 안 되던 문제, 카드를 지운 뒤 새 카드가 지워진 카드의 기준 신호를 써서 조용히 잘못된 TF가 나오던 문제, 마이크 보정이 잘린 오프셋을 저장하면서 "맞음(✓)"이라 표시하던 문제 수정
  • 안정성 잔손질 — RTA가 신호를 못 받을 때 화면이 몇 초씩 멈추던 것, 오라제이션 Room 버튼 영구 비활성·삭제된 캡처 재생, SPL 창 여닫을 때 메모리 누적, 딜레이 찾기 실패 시 버튼 잠김, 캡처 삭제 중 재클릭 오류, True Peak 리셋이 PLR/PSR에 반영 안 되던 것 등 정리
  • 앱 시작이 약 4배 빨라졌습니다 — 실행 후 창이 뜨기까지 약 4.4초 → 1.1초. 무거운 초기화를 실제로 필요할 때까지 미루도록 정리(첫 측정이 느려지지 않게 백그라운드 예열 포함)
  • 레티나 화면에서 그래프가 실제 해상도로 — 스펙트로그램과 저장된 캡처 곡선이 저해상도로 그린 뒤 늘려 표시돼 뭉개지던 것을, 화면의 실제 픽셀로 직접 그리도록 수정 — 가는 톤·좁은 피크·캡처 곡선이 또렷해집니다(속도는 그대로)
  • 창 크기 조절이 부드러워졌습니다 — 드래그 내내 반복되던 무거운 다시 그리기를 크기가 정해진 뒤 한 번만 하도록 변경. 스펙트로그램 60초 기록이 창을 1픽셀만 움직여도 사라지던 문제도 해결
  • SPL LEQ가 실제보다 크게 나오던 문제 수정(정확성) — 평균 구간을 고정값으로 가정해 6~16% 긴 구간을 평균하고 있었습니다(진행 바도 같은 비율로 어긋남). 실제 갱신 속도를 측정해 계산 — 60초 설정이 정확히 60초
  • 장치 전환·재연결 멈춤 단축 · 테마 전환 깜빡임 · 라이트 모드 TF 커서 대비 정리
  • 팝아웃(분리) 창 잔손질 — 여닫을 때마다 쌓이던 메모리 누수, 팝아웃 버튼 고착, 분리한 Spectrum 창의 우클릭 메뉴·단축키, 벡터스코프·레이더 창의 풀스크린 위 표시 동기화
  • TF 캡처 저장 파일 경량화 — 곡선을 압축된 형식으로 저장해 파일 크기·저장 시간 감소(기존 파일도 그대로 열립니다)
v2.0.12026.08

구조 재정비 · Smaart 정합 기능

앱 전체를 기능별 모듈로 재정비하고(동작은 그대로), 프로 측정기(Smaart)와의 격차를 좁히는 기능들을 더했습니다. 오라리제이션·TF 줌/팬 등 v1.9 작업도 함께 담았습니다.

  • 글랜스 쇼 모드 — FOH 풀스크린 (신규) — 객석 건너편에서도 읽히는 거대한 SPL 숫자 + 라이브 스펙트럼을 풀스크린으로. 한계 대비 초록(여유)→노랑(접근)→빨강(초과) 신호색으로 공연 중 음압을 멀리서 감시. View → Show Mode 또는 ⌘⇧F, 나가기 Esc/F
  • 코히런스 블랭킹 — Transfer Function (신규) — TF 크기 곡선을 신뢰도(코히런스)에 따라 진하게/흐리게 표시. 믿을 구간은 선명, 낮은 구간(저역·반사)은 자연스럽게 흐려져 어디를 믿을지 한눈에(Smaart식 연속 페이드). Magnitude 우클릭 → Coherence blanking
  • THD 측정 — 총고조파왜곡 (신규) — 사인 신호의 배음 왜곡률(%)을 커서 리드아웃에 표시. 커서를 기본파 봉우리에 올리면 THD n%(2·3·4·5차 자동). 스펙트럼 우클릭 → Show THD로 켤 때만
  • Transfer Function 레벨바 Peak 표시 (신규) — Reference·측정 레벨바에 순간 최대(Peak)를 흰 틱으로 함께. 채움=평균(RMS), 흰 틱=순간 피크 — 평균은 안전해 보여도 피크가 클리핑 근처면 바로 보임(Smaart식, peak-hold)
  • SPL Alarm 창 리디자인 — 개념·기능은 그대로, 보이는 방식만 새로. 번지던 신호등 글로우 → 또렷한 3분할 상태 바, 배경은 평소(안전) 중립 다크·AMBER/OVER일 때만 상태색 워시(초록 상시노출 제거), 숫자 세리프→sans, LEQ 진행 바→세그먼트, 핀·설정을 Lucide 라인 아이콘으로 통일
  • SPL 미터 카드도 같은 언어로 통일 — 각 지표 카드를 Alarm 창과 한 가족으로: 수치 sans 숫자, 하단 존 글로우는 주의(노랑)·위험(빨강)일 때만(초록 상시노출 제거), 카드 라운드 정돈. 지표색(A=소프트블루/C=소프트와인) 유지
  • 커서 리드아웃 — 주파수를 메인으로 크게 — 커서 태그에서 주파수(음이름 포함)를 가장 큰 글씨(18pt)로, 곡선 색으로 강조하고 dB는 아래 보조로 차분하게(예전엔 dB 강조·주파수 흐림). 어느 주파수를 보는지 한눈에 — 스펙트럼·TF 공통
  • 커서 값 표시 안정화 — 커서 값(dB·THD)과 우상단 최대 주파수 배지가 매 순간 튀지 않고 차분하게(시간기반 평활). 옮기면 즉시 반응
  • 내부 구조 재정비 — 앱 전체를 하나의 큰 파일에서 기능별 모듈 패키지로 분리. 보이는 동작은 100% 그대로, 앞으로 기능 추가·수정이 더 안전하고 빠르게
  • 측정 마이크 장시간 조용히 멈춤 수정 — 자동 복구 — macOS가 측정 중(특히 화면 꺼질 때) 내장 마이크를 잠깐 "사라졌다"고 알려오면 측정이 멈추는데 장치가 돌아와도 다시 켜주는 동작이 없어 방치되던 것을, 이제 돌아오면 자동으로 다시 시작. 유휴 절전 차단·콜백 순간 끊김 시 같은 장치 재오픈도 함께
  • 캡처가 전혀 되지 않던 문제 수정 — 구조 재정비 회귀로 스펙트럼·TF에서 캡처(Space)가 아무 일도 안 하던 것 수정(캡처 색 팔레트 초기화 누락)
  • 앱 안에서 릴리즈 노트·사용 설명서가 안 열리던 문제 수정 — 같은 회귀로 Release Notes·사용 설명서가 "파일을 찾을 수 없습니다"로 뜨던 것 수정(리소스 경로가 잘못된 폴더를 가리킴)
  • 캡처 색이 라이브 곡선 색과 겹치던 문제 수정 — 캡처 색을 자동으로 고를 때 지금 화면의 라이브 색 전부(스펙트럼 바·TF 기준·모든 카드)를 피하도록 개선. 특히 두 번째 캡처가 라이브 초록과 같은 초록으로 나오던 것 해결
  • — 이하 v1.9 작업 —
  • 다채널 채널 선택 — 격자 피커 (신규) — 입력 많은 인터페이스(예: 64채널)에서 채널을 화면 밖으로 넘치던 긴 목록 대신 번호 격자로. 64채널도 8×8 한 화면, 스크롤·드래그 없이 클릭 한 번 선택(채널 많을 때만 격자). 모든 드롭다운에 스크롤 안전망 추가
  • 스펙트럼 소스별 개별 시작/정지 (신규) — 각 입력 카드에 Start(전원 LED) 버튼. 마이크(소스)마다 따로 측정 on/off — 1번만 켜고 2번은 꺼두기 가능. 측정 중=LED 파랑 발광 / 꺼짐=흐린 링. 곡선 표시(✓)와 별개. 전역 Start 버튼은 없애고 S 키로 전부 시작/정지
  • 🎧 오라리제이션 (신규) — 측정한 임펄스 응답(IR)에 음악을 통과시켜 그 공연장·그 스피커로 재생된 것처럼 헤드폰으로 듣기. 원음(Dry) ↔ 공간(Room) 버튼으로 A/B, 라이브 IR·캡처 중 선택. Transfer Function 툴바 🎧 버튼
  • Transfer Function 주파수축 줌/팬 (신규) — Magnitude·Phase를 특정 대역으로 확대: 휠(커서 기준) · 드래그(박스 줌) · Shift+드래그(이동) · Cmd +/− · 더블클릭/Cmd 0(리셋). 매그·위상·코히런스가 같은 축으로 연동
  • 🎚️ TF 라이브 멀티마이크 평균 — 공간 평균 (신규) — 마이크를 객석 여러 위치에 두고 동시 측정 시 그 구역의 평균 주파수 응답을 실시간 곡선(AVG)으로. TF 툴바 Σ 버튼을 누르면 바로 평균 시작(다시 누르면 끔), 카드 목록 맨 아래 AVG 카드(곡선색 체크박스·마이크 수·표시/숨김 ✓) 등장. 켜질 때 뜨는 마이크 체크리스트(또는 AVG 카드 클릭)에서 평균 대상 선택(카드 avg 토글과 동기). 위치마다 거리 달라도 크기(파워)만 평균해 위상 영향 없이 평균 톤 밸런스. 평균만으로 개별 숨기고 AVG만. 정지 곡선을 합치는 캡처 평균과 달리 측정 중 실시간 갱신
  • 캡처 불러오기 (신규) — 내보낸 캡처 CSV를 다시 불러와 복원. Magnitude·Phase·Coherence는 물론 임펄스 응답(IR)까지 되살려 표시. 캡처 드로어 ↑ 버튼
  • dB 세로축 수동 고정 (신규) — 세로축 상·하한을 정확한 dB 값으로 직접 입력해 고정. 툴바 dB 버튼(평소 Auto)을 눌러 상·하단 입력, 잠기면 버튼이 파란 +N/−N 표시. 측정값이 변해도 안 바뀜. 해제=대화상자 [자동] 또는 눈금 더블클릭. 스펙트럼·TF 공통, 재시작에도 유지
  • 세 탭 툴바 전면 리디자인 (프로 계측기 스타일) — Spectrum·TF·Stereo 상단 컨트롤 바를 하나의 새 디자인으로 통일. 둥근 버튼 나열 → 테두리 없는 컨트롤 + 직관 아이콘 + 활성만 파랑 강조(토글=LED 점) + 모노스페이스 숫자. 조작감 동일(값=클릭 드롭다운, hover 시 클릭영역 표시)
  • 상단 탭 바 정돈 — 탭을 아이콘+이름으로, 활성 탭은 이름 폭에 맞는 파란 밑줄로. 겹치던 가로줄 정리로 상단이 깔끔. 탭 아이콘도 뜻 명확(스펙트럼=막대·TF=비교·Stereo=음량)하게 겹침 없이 정리
  • 오른쪽 패널·마이크 카드·캡처 목록까지 같은 결로 — 정보 패널을 하나의 외곽 프레임 + 얇은 구분선으로(레벨 표시는 그대로), 마이크 카드는 큰 숫자 레벨로. 캡처 목록은 무거운 상자·체크박스를 걷어내고 배경 위에 곡선색 이름만 — 왼쪽 색 점을 눌러 표시/숨김 토글. 툴바·패널·목록 배경색 통일
