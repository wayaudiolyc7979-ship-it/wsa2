# v1.7 — Transfer Function 2-Engine 설계 (MTW + Farina ESS)

- 작성일: 2026-06-20
- 브랜치: `feature/v1.7-engines`
- 헤드라인 기능: TF 측정을 **단일 고정 FFT** 한 가지에서 → **MTW(라이브)** + **Swept-Sine/Farina(정밀)** 두 엔진 체제로 확장. 기존 단일 FFT 엔진은 MTW로 "승격"(라이트 폴백으로만 잔존 고려).
- 목표: Smaart의 MTW, 그리고 Farina ESS(REW/ARTA급)에 **최대한 충실**하게 재현. 하드웨어 없이 합성신호로 헤드리스 자가검증.

---

## 1. 배경 / 현재 상태

현재 TF 엔진 (`TransferFunctionWindow`, `wayaudo2.py:9965`):
- **라이브**: 단일 고정 FFT(`TF_FFT_SIZES=[4096,8192,16384,32768]`). `_on_frame(ref,meas)`가 매 프레임 `fft_size` 롤링 버퍼 제공 → `_render_inner`에서 `Sxy/Sxx/Syy` EMA 누적 → `H=Sxy/Sxx`, `γ²=|Sxy|²/(Sxx·Syy)` → `_tf_smooth`로 로그 1200점 + 분수옥타브 스무딩.
  - 약점: 윈도우 길이가 하나 → 저역 분해능과 고역 반응속도가 트레이드오프. 저역(<100Hz) 디테일 부족.
- **스윕**: 이미 절반 구현됨. `_gen_log_sweep`(:6879) + `arm_sweep_capture`/`sweep_captured`(:9038) + `_on_sweep_captured`(:11867)에서 **Wiener 디컨볼루션** `H=MIC·REF*/(|REF|²+ε)`.
  - 약점: 고조파 왜곡(THD) 분리 없음, 코히런스를 1.0으로 가짜 표기, 멀티스윕 평균 없음, duplex(동일장치)만.

캔버스 입력 계약(불변):
- `mag_cvs.set_data(f, mag_dB, coh, phase)`
- `phase_cvs.set_data(f, ph_wrap, ph_unwr, grp_ms, coh, mag)`
- `ir_cvs.set_data(t_ms, h)`

→ **두 엔진 모두 이 계약대로만 출력하면 캔버스/캡처/익스포트 전부 재사용**된다. 이게 통합의 핵심.

## 2. 엔진 A — MTW (Multi-Time-Window), 라이브

### 2.1 원리 (Smaart 충실 재현)
- 멀티레이트: 전 대역 단일 FFT 대신, **옥타브 단위로 ÷2 데시메이션**한 여러 스테이지에서 각각 고정 크기 소형 FFT.
- 스테이지가 낮아질수록(저역) 동일 FFT 크기라도 샘플레이트가 절반 → **빈 간격 절반, 시간창 2배** → 저역에서 ~1Hz급 분해능 + 고역에서 빠른 시간응답. (Constant-Q 유사)
- 창 함수: Hann(MTW 기준).
- 출력: 로그 등간격 ~800포인트로 대역별 결과를 stitch.

### 2.2 스테이지 구성 (확정 파라미터)
- `N_FFT_STAGE = 8192` (스테이지당 고정, 설정 가능)
- `N_STAGES = 8` (48kHz 기준 충분: 최저 스테이지 SR ≈ 48000/2^7 = 375Hz → bin ≈ 0.045Hz, 시간창 ≈ 21.8s 등가)
- 스테이지 s (s=0..N_STAGES-1): 유효 샘플레이트 `sr_s = sr / 2^s`.
  - 데시메이션: 직전 스테이지 신호를 안티앨리어스 저역통과(폴리페이즈 FIR 또는 `scipy.signal.decimate`, zero-phase) 후 ÷2.
  - 각 스테이지의 **담당 주파수 대역**: 상한 = `sr_s · BAND_HI_FRAC` (예: 0.45·Nyquist 영역), 하한 = 다음(더 낮은) 스테이지 상한. 즉 각 스테이지는 자기 Nyquist 근처 ~1옥타브 구간을 담당.
  - 스테이지 0은 상한 = 20kHz(또는 0.45·sr).
- 경계 crossover는 로그축에서 인접 스테이지를 **선형 크로스페이드(½옥타브 폭)**로 블렌딩 → 이음새 아티팩트 제거.

### 2.3 누적/상태
- 스테이지별 상태 `{Sxy_s, Sxx_s, Syy_s, n_s}` 유지(EMA, 현재 단일FFT와 동일한 워밍업→1/N→EMA 정책).
- 매 프레임: 마스터(최장) 버퍼에서 각 스테이지용으로 데시메이션 → 최근 `N_FFT_STAGE` 샘플 Hann FFT → `Sxy_s` 등 갱신.
- 결과: 스테이지별 `H_s = Sxy_s/Sxx_s`, `coh_s = |Sxy_s|²/(Sxx_s·Syy_s)` → 로그 그리드에 stitch → 복소 `H(f)`, `coh(f)`.

### 2.4 출력 변환
- stitch된 `H(f_log)` → mag(dB), phase(wrap/unwrap), group delay → `mag_cvs`/`phase_cvs`.
- IR: stitch된 H를 균일 그리드로 재구성 후 `irfft` → `ir_cvs` (기존 `fftshift` 0중심 방식 유지). 저역까지 정확한 긴 IR 확보.
- 딜레이 보정(`self.delay_ms`)은 기존과 동일하게 위상에 적용.

### 2.5 순수 함수 / 상태 객체 (테스트 용이)
- `class MTWEngine`: `__init__(sr, n_fft=8192, n_stages=8, ...)`, `push(ref_long, meas_long)`, `result() -> (f, H_complex, coh)`, `reset()`.
- 마스터 버퍼 길이 = `n_fft · 2^(n_stages-1)` (최저 스테이지가 한 FFT 채우는 데 필요한 원본 샘플 수).
- 완전 헤드리스 테스트 가능(아래 §4).

## 3. 엔진 B — Swept-Sine / Farina ESS, 정밀

### 3.1 ESS 생성 (`_gen_ess`)
- `L = T / ln(f2/f1)`, `x(t) = sin[ 2π·f1·L·(e^{t/L} − 1) ]`, t∈[0,T).
- (선택) Novak 동기화: `L`을 `round(f1·T/ln(f2/f1))/f1`로 양자화해 고조파 위상 정합 향상.
- 시작/끝 짧은 페이드(클릭 방지). 기존 `_gen_log_sweep`을 이 형태로 정리/대체.

### 3.2 역필터 (`_ess_inverse`)
- 시간 역전 `x(T−t)`에 **지수 진폭 엔벨로프**(+6 dB/oct 보정) 곱: 진폭 ∝ `e^{−t/L}`(역전 신호 기준, 고역단 감쇠/저역단 부스트로 ESS의 −3dB/oct + 매칭필터 −3dB/oct = −6dB/oct를 평탄화). 정규화로 선형 IR 피크가 t=0에서 단위 이득.

### 3.3 디컨볼루션 & 분리
- 측정 응답 `y`를 역필터와 (FFT 곱) 컨볼루션 → 전체 IR `g`.
  - **선형 IR**: t≈0(시스템 딜레이) 주변. n차 고조파는 `Δt_n = L·ln(n)` 만큼 **앞쪽(음수시간)**에 출현.
  - 선형 부분만 윈도우(다음 고조파 `Δt_2 = L·ln2` 이전까지) → `rfft` → **선형 H(mag/phase)** (왜곡 무오염).
  - 각 고조파 피크(`−Δt_n`) 윈도우 → `rfft` → HHFR → **THD(f)** 계산.
- 코히런스 대체: 멀티스윕 평균 시 분산 기반 신뢰도, 단일 스윕은 선형 IR 윈도우 밖 에너지/노이즈 플로어로 SNR 표기(1.0 가짜 제거).
- 정렬: 동시 캡처된 `ref`로 스윕 시작 위상 정렬(상호상관) 후 `meas`에 적용 → 루프/페이드로 인한 오프셋 보정. (또는 캡처를 버퍼 경계에서 arm.)

### 3.4 출력
- 선형 H → `_tf_smooth`로 mag/phase/grp → `mag_cvs`/`phase_cvs`. coh=SNR 기반.
- 선형 IR → `ir_cvs`.
- THD(f)는 v1.7 1차에서는 mag 캔버스 보조 트레이스 또는 별도 라벨로 표기(범위는 §6 YAGNI 참고).

### 3.5 순수 함수 (테스트 용이)
- `_gen_ess(T, f1, f2, sr) -> x`
- `_ess_inverse(x, T, f1, f2, sr) -> inv`
- `farina_analyze(y, x, inv, sr, T, f1, f2) -> {H, freqs, ir, harmonics:{n: (t, ir_n, hhfr)}, thd}`

## 4. 검증 전략 (헤드리스, 하드웨어 불필요)

핵심: **두 코어 모두 합성신호로 정답을 알고 검증.**

### MTW
1. 알려진 시스템: 순수 딜레이 D + 1차 IIR/FIR 필터(예: 1kHz LPF).
2. 합성 ref=pink noise, meas = 필터(ref) 딜레이 D. 프레임 단위로 `MTWEngine.push` 반복.
3. assert: 복원된 `mag(f)`가 필터 이론 응답과 ±0.5dB 이내(특히 저역 50/100Hz에서 단일FFT보다 분해능↑ 확인), 위상이 딜레이+필터와 일치, `coh≈1`.

### Farina
1. 알려진 선형 필터 H_lin + 다항 비선형(`y = g + a2·g² + a3·g³`)으로 고조파 주입.
2. `farina_analyze` 실행.
3. assert: (a) 선형 H가 H_lin과 ±0.5dB, (b) 2·3차 고조파 피크가 `−L·ln(2)`, `−L·ln(3)` 위치(±몇 샘플)에 출현, (c) THD가 주입한 a2/a3와 정합.

### 통합
- `selfcheck.py`에 MTW/Farina 결과를 기존 캔버스에 그려 PNG 저장 → `Read`로 육안 확인. 새 `check()` 추가.
- 합성신호 단위테스트는 별도 스크립트(`WSA2_SETTINGS_PATH`/`WSA2_CAPTURES_PATH` 격리 규칙 준수, 단 코어는 설정파일 무관).

## 5. UI 통합

- TF 툴바에 **엔진 선택기** 추가: `MTW (Live)` / `Single FFT (Lite)` / `Sweep (Farina)`.
  - MTW 선택 시: 라이브 경로가 `MTWEngine` 사용. 마스터 버퍼 길이 = MTW 요구치로 `_EngineSyncSource`/`TFSyncThread`/`TFDuplexThread`의 `fft_size`를 마스터 길이로 설정(롤링 버퍼만 길어짐, 콜백 구조 동일).
  - Single FFT: 기존 경로 그대로(폴백/저사양).
  - Sweep: 기존 스윕 UI를 Farina 분석으로 교체.
- 멀티카드(extra pairs)도 동일 엔진 경로 사용 — 1차 구현은 primary 카드 먼저, extra는 단계적.
- `_diag()` 전환 로깅: 엔진 전환, MTW 스테이지 수렴, Farina 캡처/분리 완료 지점.

## 7. 리스크

- **MTW IR 재구성**: 스테이지별 다른 SR을 단일 균일 그리드 IR로 합치는 부분이 까다로움 → 1차는 mag/phase 우선, IR은 최장 스테이지 기반 근사 후 정교화.
- **데시메이션 비용**: 매 프레임 8스테이지 decimate는 CPU 부담 → 폴리페이즈/누적 데시메이션 캐시로 최적화. 30fps 렌더 타이머 분리 패턴 준수(콜백은 저장만).
- **Farina 정렬**: 루프 버퍼 캡처 위상 오프셋 → ref 상호상관 정렬 또는 버퍼경계 arm으로 해결.
- 단일 파일(17.8k줄) 거대 함수 → 코어는 모듈 수준 순수 함수로 분리해 테스트/가독성 확보.
