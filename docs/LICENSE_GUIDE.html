① 라이선스가 뭐예요?

손님이 SPECTRA를 사면, 그 손님 컴퓨터에서만 앱이 켜지도록 해주는 "열쇠"입니다.
아무나 복사해서 공짜로 못 쓰게 막는 장치예요.

② "전에는 프로그램 방식인데… 지금은?"

걱정 마세요. 그 프로그램 그대로 있고, 사용법도 똑같습니다. 바뀐 건 자물쇠 종류뿐이에요 (더 튼튼해짐).

전 (v1.0)지금
발급 프로그램있었음그대로 있음 ✓
앱의 활성화 창있었음그대로 있음 ✓
자물쇠 방식HMAC (옛 방식)Ed25519 (새 방식) + 옛 방식
옛날 손님 열쇠—지금도 작동함 ✓

왜 바꿨나: 옛 방식은 앱 코드 안에 "비밀번호"가 들어있어서, 코드를 뜯어보면 가짜 열쇠를 만들 수 있었어요. 새 방식은 진짜 도장이 사장님 맥에만 있어 코드를 털려도 위조 불가합니다.

③ 열쇠 만드는 2가지 방법

방법 A. 프로그램(클릭) 방식 쉬움 · 추천

터미널 안 치고, 창에서 칸 채우고 버튼만 누르면 됩니다. 발급 내역도 자동 기록돼요.

python3 wsa2_license_tool.py

창이 뜨면:

  1. 머신 ID 칸에 손님이 보낸 12글자 입력 (예: 8BDFC136A562)
  2. 고객 이름 입력 (선택 — 나중에 누구 키인지 알아보려고)
  3. 만료 연도: 0 = 영구, 또는 2027 같은 연도
  4. [키 생성] 버튼 클릭 → 열쇠가 나옴 → [클립보드 복사]
  5. 아래 발급 내역 표에 자동 저장 (CSV로 내보내기도 가능)

방법 B. 터미널(타이핑) 방식

간단히 한 명만 빠르게 발급할 때.

python3 generate_license.py

물어보는 대로 답하면 됩니다 → ① 머신 ID 입력 → ② 만료 연도(0=영구) → 열쇠 출력.

④ 손님 한 명 처리 — 전체 흐름

  1. 손님 — 앱을 켜고 우측 아래 License → [머신 ID 복사] → 나온 12글자를 카톡/메일로 사장님께 보냄
  2. 사장님 — 위 방법 A 또는 B로 그 머신 ID를 넣고 열쇠 발급
  3. 사장님 — 만든 열쇠(긴 글자)를 손님에게 보냄
  4. 손님 — 앱 활성화 창에 열쇠 붙여넣고 [활성화] → 끝! 그 컴퓨터에서 영구 사용
💡 열쇠는 그 손님 컴퓨터 1대 전용이에요. 다른 PC에 넣으면 "이 컴퓨터에 발급된 키가 아닙니다"라고 뜹니다 — 불법 복제 차단.

⑤ ⚠️ 제일 중요 — 개인키(도장) 백업

license_ed25519_private.key = 라이선스 마스터 도장 (64글자 텍스트). 이 맥에만 있습니다.

  • ✅ 비밀번호 관리자(1Password 등)에 "보안 노트"로 저장 — 추천
  • ✅ 또는 암호화 USB / 안전한 외장 백업
  • 🚫 git 커밋·이메일·클라우드 평문 저장 금지

잃어버리면: 기존 손님은 계속 쓸 수 있지만 새 열쇠를 영영 못 만듭니다. (복구는 "키 교체" 작업 필요 — 그때 Claude에게 요청)

⑥ 자주 묻는 것

Q. 옛날 v1.0 손님들 열쇠는 이제 안 되나요?

잘 됩니다. 앱이 새 열쇠·옛 열쇠 둘 다 받아주는 방식이라, v1.0 때 받은 열쇠도 그대로 작동해요.

Q. 손님이 컴퓨터를 바꾸면요?

새 컴퓨터의 머신 ID를 다시 받아서 새 열쇠를 발급해주면 됩니다.

Q. 머신 ID가 뭐예요?

손님 컴퓨터의 하드웨어로 만든 12자리 지문이에요. 컴퓨터마다 달라서, 열쇠를 그 컴퓨터에 묶는 데 씁니다.

Q. 만료 연도는 뭘 넣나요?

0이면 영구(평생). 2027을 넣으면 2027년 12월 31일까지만 작동해요. 보통은 0.
