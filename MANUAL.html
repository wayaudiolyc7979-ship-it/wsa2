이 설명서는 처음 쓰는 분도 따라 할 수 있게 만들었어요. 어려운 오디오 용어는 그때그때 쉬운 말로 풀어드릴게요. 순서대로 읽으셔도 좋고, 왼쪽 목차에서 필요한 부분만 보셔도 됩니다. 각 화면 그림 아래에는 버튼마다 번호(①②③)를 붙여 "이 버튼이 무슨 일을 하는지" 하나하나 설명해 두었습니다.

1SPECTRA가 뭐예요?

한마디로 — 소리를 눈으로 보는 도구입니다.

우리 귀에는 소리가 그냥 "크다 / 작다"로 들리지만, 사실 소리 안에는 낮은 음(저음)부터 높은 음(고음)까지 수많은 성분이 섞여 있어요. SPECTRA는 마이크나 오디오 신호를 받아서 어느 음이 얼마나 크게 들어있는지를 실시간 그래프로 보여줍니다.

이런 분께 좋아요 — 음향 엔지니어, 공연/설치 음향, 스튜디오, 방송 라우드니스 관리, 스피커·방 음향 튜닝, 그리고 "내 소리가 어떻게 생겼나" 궁금한 누구나.

3개의 탭으로 나뉘어 있어요. 각각 다른 일을 합니다:

탭한 줄 설명이럴 때 써요

3알아두면 좋은 기초 (1분 컷)

그래프를 읽으려면 이 3가지만 알면 돼요.

용어쉽게 말하면
주파수 (Hz)음의 높낮이. 숫자가 작으면 저음(둥둥), 크면 고음(쨍). 그래프의 가로축이에요. (20Hz~20kHz가 사람 귀 범위)
레벨 (dB)소리의 크기. 위로 갈수록 큼. 그래프의 세로축이에요. dB는 0에 가까울수록 크고, 음수(-60 등)로 갈수록 작아요.
dBSPL실제 공기 중 소음 크기(데시벨). 도서관 ~40, 대화 ~60, 콘서트 ~100. 정확히 보려면 마이크 캘리브레이션이 필요해요(9번).
정리하면 — 가로 = 음의 높낮이, 세로 = 소리 크기. 산봉우리가 높이 솟은 위치가 "그 음이 강하게 들어있다"는 뜻이에요.

▶ Start / ■ Stop (트랜스포트)

분석을 켜고 끄는 방법은 탭마다 조금 달라요. S 키는 Spectrum · Stereo Loudness에서 전체 시작/정지입니다(Transfer Function은 측정 카드마다 따로 켜고 꺼요).

  • Spectrum v2.0 — 전역 Start 버튼 대신 각 입력 카드의 전원 LED 버튼으로 소스마다 따로 켜고 꺼요(S=전부 토글). 측정 중이면 LED 파랑.
  • Stereo Loudness — 툴바의 Start (S) 버튼(또는 S).
  • Transfer Function — 측정 카드의 전원 LED로 카드별 시작/정지(신호 발생기 G와 별개).
세 탭은 오디오 엔진을 공유해서, 같은 장치를 여러 탭이 동시에 측정할 수 있어요. 예: Spectrum으로 보면서 Stereo Loudness도 같이 돌리기.

우측 패널 — LEVEL · INFO · INPUT

화면 오른쪽 세로 패널이에요. Spectrum·Transfer Function 툴바 맨 오른쪽 아이콘으로 접었다 펼 수 있습니다(Stereo Loudness엔 접을 우측 패널이 없어 이 버튼도 없어요). 각 구역(LEVEL·INFO·INPUT) 제목 앞에 액센트 색 아이콘이 붙고 아래 얇은 구분선이 들어가, 하나의 외곽 프레임 안에서 구역이 한눈에 구분돼요 v2.0.

구역보여주는 것
LEVEL현재 SPL(소음 크기), Peak Hold(최고값), Dominant(가장 강한 주파수), dBA / dBC(사람 귀 보정 소음치), LAeq / LCeq(평균 소음). 값은 계열별로 색이 달라요 — 광대역(SPL·Peak·Dominant)=흰색, A가중(dBA·LAeq)=소프트 블루, C가중(dBC·LCeq)=소프트 와인. 색만 봐도 어느 계열인지 구분됩니다(경고·피크 색은 그대로). 헤더 우측의 두 아이콘 — 신호등=SPL 알람 창(11번)·dB=SPL Meter 창(10번) — 은 평소엔 은은한 회색, 마우스를 올리면 소프트 블루로 살아나요.
INFO현재 설정 정보 — 샘플레이트 · FFT 크기 · 해상도(Hz) · 캘리브 값 · 반응 속도. 값은 흰색으로 또렷하게 표시돼요.
INPUT분석할 장치와 채널 선택. 각 카드에 전원 LED(측정 ON/OFF)·표시 토글·장치명·채널·레벨미터가 있어요. ＋ Add Source로 여러 장치/채널을 동시에 겹쳐 볼 수 있습니다(각 카드 색으로 구분). 카드 구성(추가·삭제·이름·채널)은 바뀔 때마다 자동 저장되어, 앱을 껐다 켜도 종료 시점 그대로 복원돼요.

패널 맨 아래에는 Help · Log · License 작은 버튼 3개가 있어요(각각 설명서·로그 내보내기·About 창).

A/C 가중이 뭐예요? — 사람 귀는 모든 음을 똑같이 듣지 않아요. dBA는 사람 귀 느낌에 맞춘 소음치(소음 측정 표준), dBC는 저음까지 포함한 값입니다. LAeq/LCeq는 그 값을 일정 시간 평균낸 거예요.
앱을 다시 열면 마지막에 보던 탭으로 시작합니다 v2.0 — 탭 레이아웃과 각 탭의 컨트롤 설정도 함께 복원돼요.

5창 분리 (팝아웃)

탭을 떼어내 별도 창으로 띄울 수 있어요. (듀얼 모니터에 좋아요)

탭을 별도 창으로 (팝아웃)

  • View 메뉴에서 "○○ in Separate Window"를 고르거나, 단축키 ⌘⇧S(Spectrum)·⌘⇧T(TF)·⌘⇧L(Stereo)를 누르면 그 탭이 독립 창으로 떨어져요.
  • 창은 본체와 따로 움직이고, 위치·크기를 기억합니다. 닫으면 다시 본체 탭으로 돌아와요.
  • 오디오 엔진을 공유하므로 분리해도 측정은 그대로 흐릅니다.
  • TF 별도 창엔 캡쳐 패널도 함께 (v1.8) — Transfer Function을 별도 창으로 분리하면 캡쳐 목록 패널이 그 창으로 함께 이동해요. 멀티모니터에서 캡쳐를 바로 켜고/끄고 관리할 수 있습니다(창을 닫으면 패널도 본체로 돌아옴).
  • 반대로 Spectrum 별도 창에는 캡쳐 패널이 따라가지 않아요 — 그 창에서는 캡쳐 패널 토글 아이콘이 표시되지 않고, 캡쳐 관리는 본체 창에서 합니다.

벡터스코프 · 레이더 팝아웃

Stereo Loudness 탭의 벡터스코프와 라우드니스 레이더는 각 그림 모서리의 ↗ 아이콘으로 각각 별도 창으로 띄울 수 있어요(8번).

맥에서 전체화면(풀스크린) 중에도 별도 창/미터가 본 화면 위에 정상 크기로 떠요. 검은 화면이나 다른 데스크탑(Space)으로 튀지 않습니다.

툴바는 테두리 없는 컨트롤 + 직관 아이콘 + 켜짐만 파란 강조로 정돈돼 있어요(토글은 작은 LED 점). 값은 눌러서 드롭다운으로 고릅니다. 아래 번호는 왼쪽부터 오른쪽 순서 그대로예요.

소스별 개별 시작 / 정지 · 색 변경 v2.0

  • 소스별 Start(전원 LED) — 각 입력 카드에 전원 LED 버튼이 있어요. 마이크(소스)마다 따로 측정을 켜고 끌 수 있습니다(예: 1번만 켜고 2번은 꺼두기). 측정 중이면 LED가 파랗게 빛나고, 꺼지면 흐린 링이 돼요. 곡선 표시/숨김(✓)과는 별개(측정하면서 곡선만 숨기기 가능). S 키는 전부 한 번에 시작/정지.

화면 읽는 법

가로축이 주파수(저음 왼쪽 → 고음 오른쪽), 세로축이 크기(dB)예요. 소리가 들어오면 울퉁불퉁한 곡선이 춤춥니다. 봉우리가 솟은 곳 = 그 음이 강한 것.

그래프에 마우스를 올리면 그 지점의 값이 커서 태그로 떠요. 주파수(음이름 포함)를 가장 크게, 곡선 색으로 강조하고 dB는 아래 보조로 표시합니다 v2.0 — 지금 보는 주파수가 한눈에.
THD 측정 (총고조파왜곡) v2.0 — 사인 신호의 배음 왜곡률(%)을 볼 수 있어요. 스펙트럼을 우클릭 → Show THD로 켜고, 커서를 기본파 봉우리에 올리면 그 주파수 기준 THD n%가 한 줄 뜹니다(2·3·4·5차 배음 자동). 스피커·앰프의 왜곡 성능 확인용.
측정을 시작하기 전에는 그래프에 "Press Start" 안내만 깔끔하게 표시돼요 — 시작 전에는 막대·바닥선이 그려지지 않습니다(v1.8에서 정리).
마우스를 그래프 위에 올리면 그 지점의 주파수·dB(·음이름)이 작은 정보창으로 떠요. 더블클릭하면 세로축이 데이터에 맞게 자동 정렬됩니다. ↑↓로 dB 범위를 위아래로 옮길 수 있어요.

① 신호 발생기 (Signal Generator)

측정용 소리를 내보내는 부분이에요. 소스는 항상 하나만 선택되고, 기본은 Pink입니다.

  • 신호 종류 드롭다운 v2.0 — 버튼 4개가 하나의 드롭다운으로 합쳐졌어요. 눌러서 Pink · White · Sine… · Sweep… · File… 중 고르면 현재 선택이 셀에 표시됩니다(예: Pink, Sine 1k, Sweep).
    • Pink(핑크 노이즈) — 일반 음향 측정용 "쉬익~" 소리(가장 많이 씀, 기본).
    • White — 모든 주파수가 같은 에너지인 노이즈.
    • Sine(사인파) — 단일 주파수 순음. 버튼을 누르면 주파수(10~24000Hz)를 정해요(예: "Sine 1k"). THD 같은 단일음 점검에 유용.
    • Sweep — 저음→고음으로 훑는 1회 정밀 측정 신호. 버튼을 누르면 설정 창이 떠서 지속 시간(1~60초)·주파수 구간·상행/하행을 고를 수 있어요. 자세한 동작은 아래 "Sweep 정밀 측정" 참고.
  • File… — 직접 만든 음원 파일로 측정. 오디오 파일을 창에 끌어다 놓아도 바로 불러옵니다(WAV·FLAC·AIFF·MP3 등). 파일 자체는 저장되지 않아서, 재시작·프리셋 복원 시엔 Pink로 시작해요 — File은 그 세션에서 직접 불러올 때만 선택됩니다.
  • Level — 내보내는 소리 크기. − / + 로 조절.
  • Out — 어느 출력 채널로 내보낼지(다채널 인터페이스면 Out 3·4 등도 가능). 재생 중에 바꿔도 끊김 없이 즉시 새 채널로 전환돼요.
  • ▶ Play (G) — 신호 재생/정지.

② 기준(Reference)과 측정(Measurement)

  • Reference — "원본" 신호. 보통 Internal (SigGen)(방금 그 발생기 소리)로 둡니다.
  • Measurement — 마이크로 받은 "실제" 소리. Meas에서 마이크 장치/채널을 고르세요. 각 카드에는 레벨바(초록≤−9 / 노랑 / 빨강>−3 dBFS)가 있어 입력 크기를 확인할 수 있어요. 채움 막대(평균 RMS)에 더해 흰 틱으로 순간 최대(Peak)도 함께 표시돼요 v2.0 — 평균은 안전해 보여도 순간 피크가 클리핑 근처면 바로 보입니다.
  • 측정 카드 추가 — 여러 지점을 동시에 측정/비교(각 색으로 구분).
즉 SPECTRA가 원본(Reference) ↔ 마이크 소리(Measurement)를 비교해서 결과를 그립니다.

③ 딜레이(Delay) 맞추기 — 중요!

마이크가 스피커에서 떨어져 있으면 소리가 조금 늦게 도착해요. 이 시간차를 맞춰줘야 정확한 측정이 됩니다.

신호를 재생한 상태에서 Auto / Find 버튼(L)을 누르면 — SPECTRA가 딜레이를 자동으로 찾아 맞춰줍니다. 끝!
툴바 Units를 ms·m나 m로 바꾸면 딜레이가 거리(미터)로도 표시돼요(음속 343 m/s 기준). 측정 카드 딜레이칸 옆에 = N.NN m로 나옵니다.

④ 결과 그래프 3종 — 떠 있는 카드 3장

v1.8부터 세 그래프가 각각 떠 있는 둥근 카드로 분리됐어요. 카드마다 고유 색 제목이 붙어 지금 보는 분석이 무엇인지 바로 보입니다 — Live IR = 청록 · Phase = 보라 · Magnitude = 파랑. 그래프를 클릭해 선택하면 그 카드 상단에 SPECTRA 시그니처 그라디언트 엣지가 켜져 어느 카드를 보고 있는지 한눈에 알 수 있어요(기존 파란 사각 테두리를 대체). 카드 사이 경계에도 같은 그라디언트가 아주 옅게 흐르고, 경계를 드래그하면 카드 높이를 조절할 수 있습니다.

코히어런스(Coherence)가 뭐예요? — "이 측정값을 믿어도 되나"를 나타낸 점수예요(리드아웃에 0~100%). 주변이 시끄럽거나 신호가 약하면 낮아집니다. 높은(100%에 가까운) 구간의 결과만 신뢰하세요. v1.8부터는 점선 기준선·우측 % 눈금 없이 채움 밴드로만 은은하게 보여줘서 응답 곡선과 부딪히지 않아요 — 수치가 궁금하면 커서를 올리세요.
코히런스 블랭킹 v2.0 — Magnitude 그래프를 기본으로 켜져 있어요 — Magnitude 그래프 우클릭 → Coherence blanking으로 끌 수 있습니다. 크기 곡선이 신뢰도에 따라 진하게/흐리게 그려져요. 믿을 수 있는 구간은 선명하게, 신뢰도 낮은 구간(저역·반사·측정 한계)은 자연스럽게 흐려져 — 어디를 믿고 어디를 걸러야 할지 곡선만 봐도 바로 보입니다(Smaart의 trace blanking 방식, 연속 페이드).
자동 Y축 맞춤 (v1.8) — 측정(핑크/스윕)을 시작하면 Magnitude 그래프가 첫 데이터에서 한 번 자동으로 화면에 맞게 들어와요. 더블클릭할 필요 없이 곡선이 바로 보이고, 측정 중에는 점프하지 않습니다. 이후 수동으로 맞추려면 그래프 더블클릭=자동 정렬, ↑↓=범위 이동.

🎧 오라제이션 — 측정한 공간을 "귀로" 듣기 v2.0

측정한 임펄스 응답(IR)에 아무 음악이나 통과시켜, 그 공연장·그 스피커로 재생된 것처럼 헤드폰으로 들어보는 기능이에요. 그래프(눈)로만 보던 측정을 소리(귀)로 확인 — "객석 그 자리에 안 가봐도 그 소리를 듣는" 셈입니다.

  • TF 툴바의 🎧 버튼으로 엽니다.
  • Dry(원음) ↔ Room(공간)을 버튼으로 A/B 비교 — 원본 음악과, 그 공간을 통과한 소리를 번갈아 들어요.
  • 라이브 IR과 캡쳐들 중 골라 좌석·공연장별로 각각 들어볼 수 있어요.
측정한 그 PA로 다시 내보내면 공간이 두 번 걸려요 — 오라제이션은 반드시 헤드폰으로 들으세요.

🎚️ 라이브 멀티마이크 평균 (공간 평균) v2.0

마이크를 객석 여러 위치에 두고 동시에 측정할 때, 그 구역의 평균 주파수 응답을 실시간 한 곡선(AVG)으로 봅니다. 위치마다 스피커까지 거리가 달라도 크기(파워)만 평균하므로 그 구역의 평균 톤 밸런스가 깔끔하게 잡혀요. 한 자리만 보고 EQ를 잡으면 다른 자리에서 안 맞을 수 있는데, 여러 자리를 평균내면 전체에 고르게 맞출 수 있습니다.

① 측정 카드를 2개 이상 만들어 각 마이크로 측정 시작 → ② TF 툴바의 Σ 버튼을 누르면 바로 평균이 켜지고(다시 누르면 끔) 마이크 선택 팝업이 떠요 → ③ 팝업에서 평균에 넣을 마이크를 체크(각 마이크 카드 색으로 표시) → ④ 굵은 평균 곡선이 개별 곡선들 위에 그려집니다.
  • Σ 버튼(툴바) — 평균 켜기/끄기. 켜지면 아이콘에 파란 불이 들어와요.
  • 마이크 선택 — Σ 팝업의 체크리스트, 또는 각 측정 카드 헤더의 Σ 아이콘(평균에 넣으면 카드 색, 빼면 흐림). 둘은 서로 연동돼요.
  • AVG 카드 — 평균을 켜면 카드 목록 맨 아래에 AVG 카드가 떠요:
    • (n) — 평균에 들어간 마이크 수.
    • ✓ 체크 — 평균 곡선 표시 / 숨김.
    • 클릭 — 카드 선택(색 틴트) + 평균 곡선을 분석 화면 맨 앞으로 굵게 강조.
    • 우클릭 → 색상 변경 — 평균 곡선 색을 원하는 색으로 바꿔요.
마이크 2개 이상이 실제로 측정 중이어야 평균이 그려져요(원리상 여러 개를 합치는 것이라, 1개뿐이면 평균이 나오지 않습니다). 정지된 곡선을 합치는 캡쳐 평균(측정 후)과 달리, 이 평균은 측정 중 실시간으로 갱신됩니다.

⑤ 측정 엔진 — Single vs Adaptive

v1.7부터 측정 방식을 고를 수 있어요. 툴바 Engine 콤보에서 바꿉니다(바꾸면 분석이 재시작돼요).

엔진특징이럴 때
Single고정 크기 FFT 하나로 분석. 가볍고 단순.간단히 볼 때, 저사양에서.
Adaptive주파수 대역마다 분석 길이를 달리해 저역은 길게(촘촘히)·고역은 짧게(빠르게). 전 대역 고른 해상도.라이브 현장 튜닝 — 실시간으로 EQ 조정하며 볼 때(추천).
정밀 측정·THD가 필요하면 발생기에서 Sweep를 한 방 쏘세요. 가만히·조용한 상태에서 스윕을 재생하면 왜곡 없는 깨끗한 측정과 함께 THD/SNR 값을 얻을 수 있어요. (현장 라이브=Adaptive, 한 방 정밀=Sweep — REW/전문 측정 워크플로우와 동일)

Sweep 정밀 측정 — 이렇게 동작해요 (v1.8에서 대폭 다듬음)

  • 발생기에서 Sweep을 고르고(설정 창에서 지속 시간·주파수 구간 지정) ▶ Play를 누르면, 스윕이 한 번 재생되면서 측정 카드가 자동으로 시작돼요 — 따로 카드 Start를 누를 필요가 없습니다.
  • 측정이 끝나면 결과가 세 그래프에 뜨고 THD/SNR 값이 함께 표시돼요. 이때 카드 딜레이는 자동으로 0 ms로 맞춰집니다 — 스윕 분석은 왕복 지연을 이미 제거하므로, IR 임펄스가 0 ms 중앙에 오고 위상도 정상으로 표시돼요. 임펄스 응답은 측정 대역 경계의 잔물결(링잉)을 줄여 한층 깨끗하게 나옵니다.
  • 스윕 결과는 핑크(라이브) 측정과 같은 절대 레벨로 표시돼요(레퍼런스 채널 기준으로 정규화). 핑크 캡쳐와 스윕 캡쳐를 같은 높이에서 직접 겹쳐 비교할 수 있습니다.
  • 스윕 길이를 바꿔도(1초·2초 등) 같은 해상도·같은 레벨로 나와서 캡쳐끼리 그대로 포개져요. 단, 길이가 짧을수록 고역 해상이 낮아지는 건 스윕의 물리적 특성 — 정밀하게 보려면 길게 쏘세요.
  • 스윕이 끝나면 발생기는 다시 연속 신호(핑크 등)로 돌아가 계속 튜닝하면 돼요. 마이크 위치를 옮겼다면 핑크 재생 상태에서 Auto/Find(L)로 딜레이만 다시 맞추세요.
스윕은 조용한 상태에서 한 방이 원칙이에요. 재생 중 큰 잡음이 섞이면 THD/SNR과 저역 결과가 흔들립니다.

9마이크 캘리브레이션 (정확한 소음 측정)

화면의 dBSPL 숫자를 실제와 똑같이 맞추는 작업입니다.

마이크마다 감도가 달라서, 보정을 안 하면 화면 숫자가 실제 소음과 다를 수 있어요. 캘리브레이터(기준기)가 있으면 정확히 맞출 수 있습니다.

헤더의 Calibration 버튼 클릭 → ① 마이크에 캘리브레이터를 끼우고 켜기 → ② 기준값(94 또는 114 dBSPL) 선택 → ③ Measure Level (3s)로 3초 측정 → ④ Auto Calculate가 오프셋을 자동 계산해 맞춰줍니다.
  • 채널 목록 — 다채널 인터페이스면 채널마다 따로 보정. 채널을 고른 뒤 각각 측정하면 설정값이 채널별로 저장돼요.
  • Applied Offset — 자동 계산값을 수동으로 미세 조정할 수 있어요. Reset으로 해당 채널 보정 초기화.
캘리브레이터가 없어도 SPECTRA는 잘 작동해요. 다만 dBSPL 절대값이 정확하지 않을 뿐, 주파수 분석·상대 비교는 문제없습니다.
캘리브레이션은 Spectrum 탭·SPL 미터의 절대 SPL에 적용돼요. Transfer Function의 매그니튜드는 측정÷기준의 상대 이득(dB)이라 캘리브와 무관합니다(정상).

View 메뉴 → SPL Meter, 또는 LEVEL 패널 헤더의 dB 아이콘으로 열려요. 공연장에서 객석 소음을 모니터하거나, 측정값을 크게 띄워둘 때 좋아요. SPL 미터가 따로 열려 있지 않아도 측정은 백그라운드에서 계속됩니다.

v1.8 새 디자인 — 읽지 않아도 보이는 소음계

  • 신호등 색 번짐(글로우) — 카드 아래쪽이 주의(노랑)·위험(빨강)일 때만 은은하게 물들어요 v2.0. 평소(안전)엔 색을 아예 켜지 않아 차분하고, 색이 켜지는 것 자체가 경고가 됩니다. 수치 숫자는 Alarm 창과 같은 sans 글꼴로 통일돼 있어요.
  • 회색 배경 · 검정 카드 — 창 배경이 회색, 카드가 검정으로 반전되어 다른 화면과 톤이 통일됐고, 검정 카드 위라 글로우가 더 선명하게 보여요.
  • 값 색 = LEVEL 패널과 동일 — A가중(SPL A·LAeq)=소프트 블루, C가중(SPL C·LCeq)=소프트 와인, 광대역(Z)=흰색. 경고·피크 색(주황·빨강)은 그대로예요.
  • 시계 카드 — 소프트 화이트로 차분하게.
  • LEQ 카드 이름 — 'dB LAeq / dB LCeq' → 'LAeq / LCeq'로 짧아져 옆 카드(SPL A Slow 등)와 형식이 통일됐어요.

창 다루기

  • 압정(핀) 버튼 — 타이틀바의 압정 아이콘으로 항상 다른 창 위에 떠 있게(always-on-top) 고정/해제. 마우스를 떼면 타이틀바가 숨어 숫자판만 꽉 차요(글랜스 모드). (v1.8에서 자물쇠 → 압정 아이콘으로 정제)
  • 카드별 Max 리셋 — 각 카드 안의 ↻ 리셋 버튼으로 그 카드의 최고값(Max/피크 홀드) 기록만 초기화해요. 예전 타이틀바의 전역 'Reset Max' 버튼은 헷갈려서 없앴습니다(v1.8). 버튼에 마우스를 올리면 배경칠 없이 아이콘 색만 또렷해져요.
  • LAeq·LCeq 카드의 적분 진행 바 — LEQ 카드 하단의 SPECTRA 그라디언트 진행 바가 설정한 LEQ 시간 중 얼마나 적분됐는지 보여주고, 옆 ↻로 적분을 0부터 다시 시작해요. (LEQ 카드는 이 타이머 리셋이 Max 리셋 역할을 대신하고, 시계 카드에는 리셋이 없어요.)
  • 창 크기는 자유롭게 늘리거나 줄일 수 있고, 글자도 따라 커집니다(Smaart식 스케일).

⚙ SPL 설정 창 — 화면 구성 바꾸기

타이틀바의 기어(톱니바퀴) 아이콘을 누르면 SPL 설정 창이 열려요(v1.8에서 슬라이더 → 기어 아이콘으로 정제). 여기서 소음계를 내 마음대로 배치할 수 있습니다.

  • 측정 소스 — 어느 입력(primary 또는 추가한 소스 카드)을 SPL로 잴지 선택.
  • LEQ time — 평균값(LAeq·LCeq)을 낼 시간(1분 ~ 3시간). 예: 3 hr=3시간 평균 소음(공연·행사 누적 측정에 유용).
  • 행(Row) · 열(Col) — 숫자판을 몇 칸으로 나눌지(최대 4×4).
  • 각 칸 지표 선택 — 칸마다 보여줄 값: SPL A/C Slow · SPL Slow(Z, 1초 시정수), SPL A/C Fast · SPL Fast(Z, 125ms 시정수), LAeq · LCeq(적분 평균), Peak · Peak C · FS Peak(디지털 풀스케일 피크, dBFS), Clock(24시간 시계). 안 쓸 칸은 "— 없음"으로.
  • 다 고른 뒤 OK를 누르면 바로 반영돼요.
A 가중 vs C 가중: A는 사람 귀가 느끼는 시끄러움(법적 소음 기준에 주로 사용), C는 저음까지 포함한 전체 음압. Slow는 숫자가 천천히 부드럽게 움직여 읽기 편하고, Fast는 민감하게 반응해요.

11SPL 알람 창 (소음 한계 알람)

소음이 정해둔 한계에 가까워지거나 넘으면 신호등 색으로 알려주는 독립 창이에요.

View 메뉴 → SPL Alarm, 또는 LEVEL 패널 헤더의 신호등 아이콘으로 열립니다. 공연장 FOH에서 멀찍이 띄워두고 "지금 한계 안인가?"를 한눈에 보는 용도예요. SPL 미터와 무관한 완전 독립 창이라 미터를 안 켜도 동작합니다. 창 배경은 v1.8부터 회색으로 SPL 미터와 톤이 통일돼, 검정 카드가 배경 위에 또렷하게 떠 보여요.

  • 신호등 색 — 초록(여유) → 노랑(한계 −N dB 접근) → 빨강(초과, 깜빡임 + "N초째").
  • 거대 숫자 — 선택한 지표 값 / 한계, 그 아래 ▼여유 또는 ▲초과.
  • LAeq·LCeq 적분 진행 바 + ↻ 리셋 (v1.8) — 알람 지표가 LAeq·LCeq(적분)일 때는 카드 하단에 세그먼트형 진행 바가 나타나 얼마나 적분됐는지 보여주고, 옆 ↻ 버튼으로 적분을 0부터 다시 시작할 수 있어요(SPL 미터의 LEQ 카드와 동일한 방식). SPL A/C Slow 같은 순간값 지표일 땐 표시되지 않아요.
  • 창 크기에 맞춰 글자가 커지고, 압정(핀)으로 항상 위에, 마우스를 떼면 카드만 꽉 차요(글랜스).
  • 차분한 평소 · 위험할 때만 부각 v2.0 — 카드 배경이 중립 다크로 바뀌고, 상태색은 한계에 가깝거나(노랑) 초과(빨강)일 때만 배경에 은은히 번져요(예전엔 초록이 늘 깔려 있었어요). 신호등은 번지는 글로우 대신 또렷한 3분할 바, 숫자는 sans 글꼴, LEQ 진행 바는 세그먼트형입니다.

⚙ 알람 설정

타이틀바의 기어 아이콘으로 설정 창을 엽니다.

  • 마스터 지표 — 무엇을 기준으로 알람할지(LAeq · LCeq · dBA · dBC · SPL · Peak 등).
  • 한계(Limit) — 빨강이 되는 기준값(예: 100 dBA).
  • 노랑 여유(Amber headroom) — 한계 몇 dB 전부터 노랑으로 경고할지(예: −3 dB).
  • LEQ time — LEQ 지표일 때 평균 시간.
단위는 선택한 지표대로 표기돼요(예: "100 dB LAeq 10min"). LEQ 계열은 적분 시간(분)이 함께 붙습니다.

12캡쳐로 비교하기 (Capture)

지금 보이는 곡선을 그대로 박제해서, 나중 측정과 겹쳐 비교하는 기능이에요.

"캡쳐"는 화면 사진(스크린샷)이 아니에요. 현재 그래프를 색깔 있는 고정 곡선으로 저장해 두면, 그 위로 지금 들어오는 소리(라이브)가 계속 그려져요. 그래서 "전 vs 후", "스피커 A vs B", "이 자리 vs 저 자리"를 한눈에 비교할 수 있습니다. Spectrum·Transfer Function 탭에서 쓸 수 있어요. TF를 별도 창으로 분리하면 이 캡쳐 패널도 그 창으로 함께 이동합니다(v1.8, 5번 참고).

캡쳐하는 법

  • Capture 버튼 또는 Space — 현재 곡선을 박제. (Spectrum은 이름을 묻고, TF는 자동 이름으로 빠르게 저장.) 저장되면 ✓ Captured 표시가 잠깐 떠요.
    측정이 멈춰 있으면 캡쳐·재캡쳐가 되지 않고 안내가 뜹니다 v2.0.2 — 라이브 데이터가 없는 상태로 기존 캡쳐가 빈 곡선에 덮어써지는 걸 막기 위해서예요.
  • 캡쳐마다 다른 색이 자동 배정되고(라이브 색과 안 겹치게), 목록(서랍)에서 확인·삭제할 수 있어요. 표시/숨김은 목록 왼쪽의 색 점을 눌러 바꿉니다 — 채움=표시, 빈 원=숨김.
  • 재캡쳐(Recapture, R) — 기존 캡쳐의 색·이름·그룹은 그대로 두고 곡선 데이터만 현재 라이브로 덮어써요(제자리 다시 찍기). 행 우클릭 메뉴에도 있어요.
캡쳐는 저장돼요. 앱을 껐다 켜도 캡쳐해 둔 곡선이 그대로 남아, 어제 측정과 오늘 측정을 비교할 수 있습니다.

목록 정리 — 일괄 토글 · 그룹 · Delete All

  • 전체 표시/숨김 토글 — 목록 제목 옆 웨이브 아이콘으로 모든 캡쳐를 한 번에 켜고 꺼요. 그룹마다도 토글 가능.
  • 그룹 — ＋ Grp로 그룹을 만들고, 그룹 헤더 이름을 클릭하면 새 캡쳐가 그 그룹으로 들어가요(◉ 하이라이트). 화살표로 접기.
  • Delete All — 행/빈 공간 우클릭 → 현재 탭의 캡쳐 전체 삭제(확인 후).

TF 캡쳐 — 내보내기 (CSV + PNG) · 불러오기 (Import)

Transfer Function 탭에서는 캡쳐한 측정값을 파일로 내보내고, 다시 불러올 수 있어요.

  • 내보내기(Export) — 캡쳐 서랍 상단의 ↓(Export) 버튼으로 폴더를 고르면:
    • CSV 파일 — 주파수별 크기(dB)·위상·코히런스 숫자 데이터. 엑셀·보고서용. (tf_captures_날짜.csv)
    • PNG 그림 — 그래프 이미지. (tf_이름_날짜.png)
  • 불러오기(Import) v2.0 — 내보냈던 캡쳐 CSV를 캡쳐 서랍의 ↑ 버튼으로 다시 불러와 화면에 복원해요. 크기·위상·코히런스는 물론, CSV엔 없던 임펄스 응답(IR)도 크기+위상에서 되살려 표시합니다. 여러 캡쳐를 한 번에 불러올 수 있어요.
여러 캡쳐를 하나로 평균 (TF 평균) — 캡쳐 서랍의 평균 버튼으로 체크한 캡쳐 2개 이상을 복소 평균해 새 Avg(n) 곡선을 만들어요(크기+위상+IR까지). 여러 번 측정한 걸 하나로 합칠 때. (측정 중 실시간 평균은 위 7번 TF의 Σ 라이브 멀티마이크 평균을 보세요.)

TF — △ Delta · ⧗ 안정화 캡쳐

  • △ Delta 비교 — 곡선을 기준 대비 차이(Δ)로 표시. ① 캡쳐 목록에서 기준 캡쳐의 R 버튼으로 기준(Reference) 지정 → ② △를 켜면 나머지 곡선이 그 기준에서 얼마나 달라졌는지(±dB)만 보여요. "보정 전→후", "A 자리→B 자리" 차이 볼 때. (기준 미지정이면 동작 안 함)
  • ⧗ 안정화 캡쳐 — 바로 찍지 않고 측정이 안정될 때까지(평균·코히런스, 최대 5초) 기다렸다 깨끗한 한 장을 자동 캡쳐. "Stabilizing…" 표시 후 저장돼요. (5초 내 안정 안 되면 알리고 그대로 캡쳐 — 주변 소음↓·신호 레벨↑로 개선)
