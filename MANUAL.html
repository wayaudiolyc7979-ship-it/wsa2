SPECTRA

See your sound.
SPECTRUM ANALYZER · by WAYAUDIO

이 설명서는 처음 쓰는 분도 따라 할 수 있게 만들었어요. 어려운 오디오 용어는 그때그때 쉬운 말로 풀어드릴게요. 순서대로 읽으셔도 좋고, 왼쪽 목차에서 필요한 부분만 보셔도 됩니다.

1SPECTRA가 뭐예요?

한마디로 — 소리를 눈으로 보는 도구입니다.

우리 귀에는 소리가 그냥 "크다 / 작다"로 들리지만, 사실 소리 안에는 낮은 음(저음)부터 높은 음(고음)까지 수많은 성분이 섞여 있어요. SPECTRA는 마이크나 오디오 신호를 받아서 어느 음이 얼마나 크게 들어있는지를 실시간 그래프로 보여줍니다.

이런 분께 좋아요 — 음향 엔지니어, 공연/설치 음향, 스튜디오, 방송 라우드니스 관리, 스피커·방 음향 튜닝, 그리고 "내 소리가 어떻게 생겼나" 궁금한 누구나.

3개의 탭으로 나뉘어 있어요. 각각 다른 일을 합니다:

탭한 줄 설명이럴 때 써요
Spectrum지금 들어오는 소리의 주파수 분석"이 소리에 저음/고음이 얼마나 있나?"
Transfer Function스피커·방이 소리를 어떻게 바꾸는지 측정"이 스피커/방의 음향 특성은?"
Stereo Loudness좌우 스테레오 + 방송용 음량(LUFS) 측정"방송/음원 규격에 맞나?"

2처음 시작하기

설치

① 받은 SPECTRA 설치 파일(.dmg)을 더블클릭 → ② 열린 창에서 SPECTRA 아이콘을 Applications 폴더로 드래그 → ③ 끝! 응용 프로그램에서 실행하세요.
처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면 — 응용 프로그램 폴더에서 아이콘 우클릭 → 열기를 한 번만 해주면 그 다음부터 정상적으로 열립니다.

라이선스 활성화

처음 켜면 활성화 창이 나옵니다.

  1. 화면에 보이는 머신 ID를 복사해서 판매자에게 전달하세요. (이 PC 전용 ID예요)
  2. 받은 시리얼 키를 입력칸에 붙여넣고 활성화를 누르면 끝.
라이선스는 이 컴퓨터에 한 번만 등록하면 됩니다. 나중에 정보는 우측 아래 License 버튼(About 화면)에서 다시 볼 수 있어요.

화면 살펴보기

  • 맨 위 (헤더) — 가운데 SPECTRA 로고, 오른쪽에 ☀️ Light / 🌙 Dark(밝은/어두운 화면 전환)와 Calibration(마이크 보정) 버튼.
  • 탭 줄 — Spectrum / Transfer Function / Stereo Loudness 3개 탭.
  • 툴바 — 그 탭의 설정 버튼들이 한 줄로.
  • 그래프 — 가운데 큰 영역. 여기에 소리가 그려져요.
  • 우측 패널 — 레벨 수치, 정보, 입력 장치 선택.
가장 먼저 할 일 — 우측 INPUT에서 오디오 장치(마이크/인터페이스)와 채널을 고른 뒤, 왼쪽 위 ▶ Start를 누르면 분석이 시작됩니다.

3알아두면 좋은 기초 (1분 컷)

그래프를 읽으려면 이 3가지만 알면 돼요.

용어쉽게 말하면
주파수 (Hz)음의 높낮이. 숫자가 작으면 저음(둥둥), 크면 고음(쨍). 그래프의 가로축이에요. (20Hz~20kHz가 사람 귀 범위)
레벨 (dB)소리의 크기. 위로 갈수록 큼. 그래프의 세로축이에요. dB는 0에 가까울수록 크고, 음수(-60 등)로 갈수록 작아요.
dBSPL실제 공기 중 소음 크기(데시벨). 도서관 ~40, 대화 ~60, 콘서트 ~100. 정확히 보려면 마이크 캘리브레이션이 필요해요(7번).
정리하면 — 가로 = 음의 높낮이, 세로 = 소리 크기. 산봉우리가 높이 솟은 위치가 "그 음이 강하게 들어있다"는 뜻이에요.

4Spectrum 탭 — 실시간 주파수 분석

지금 들어오는 소리에 어떤 음들이 얼마나 들어있는지 실시간으로 봅니다.

화면 읽는 법

가로축이 주파수(저음 왼쪽 → 고음 오른쪽), 세로축이 크기(dB)예요. 소리가 들어오면 울퉁불퉁한 곡선이 춤춥니다. 봉우리가 솟은 곳 = 그 음이 강한 것.

뷰 모드 (어떻게 보여줄까)

버튼뜻쉽게
FFT가장 정밀한 분석아주 촘촘하게 본다. 정확한 주파수 찾을 때.
1/3 · 1/12 · 1/24옥타브 밴드주파수를 귀에 가깝게 묶어서 본다. 1/3은 큼직하게, 1/24는 곱게. 방/스피커 튜닝엔 1/12·1/24가 보기 좋아요.
+Spectro스펙트로그램 추가시간에 따라 소리가 어떻게 변했는지 히트맵(색)으로. 아래로 흘러내려요.
Log / Lin가로축 눈금 방식Log=사람 귀처럼 저음을 넓게(추천), Lin=고르게.

컨트롤 버튼들

버튼무엇언제/왜
SR샘플레이트(44.1~96kHz)보통 그대로. 장치에 맞춰 자동.
Avg평균 (None/4x/8x/16x)곡선이 너무 떨리면 평균을 올려 부드럽게. 정밀히 보려면 낮게.
Peak피크 홀드 ON/Reset지나간 최고값을 선으로 남겨 보여줘요. Reset으로 지움.
Hold피크 유지 시간최고값을 몇 초 붙잡을지.
Range세로축 범위(예: 96dB)표시할 dB 폭. ↑↓로 위아래 이동도 가능.
Speed반응 속도곡선이 따라오는 빠르기.
Color곡선/색 설정취향대로 색 변경.
Capture현재 화면 스냅샷 저장지금 곡선을 찰칵 박제해서 나중과 비교. Space로도 가능.

우측 패널 (LEVEL · INFO · INPUT)

  • LEVEL — 현재 SPL(소음 크기), Peak Hold(최고값), Dominant(가장 강한 주파수), dBA/dBC(사람 귀 보정 소음치), LAeq/LCeq(평균 소음). 우측 위 ↗ 아이콘으로 큰 SPL 미터 창을 따로 띄울 수 있어요(8번).
  • INFO — 샘플레이트·FFT 크기·해상도·캘리브 값 등 현재 설정 정보.
  • INPUT — 분석할 장치와 채널 선택. + Add Source로 여러 장치/채널을 동시에 겹쳐 볼 수 있어요(각 카드 색으로 구분).
A/C 가중이 뭐예요? — 사람 귀는 모든 음을 똑같이 듣지 않아요. dBA는 사람 귀 느낌에 맞춘 소음치(소음 측정 표준), dBC는 저음까지 포함한 값입니다.

5Transfer Function 탭 — 스피커·방 음향 측정

스피커나 방이 소리를 "어떻게 바꾸는지"를 측정합니다. (Smaart 같은 전문 측정과 같은 원리)

쉽게 말하면 — 한쪽으로 기준 신호를 내보내고, 다른 쪽 마이크로 실제로 들리는 소리를 받아서, 둘을 비교합니다. "원본 대비 어디가 커지고/작아지고/늦게 도착했나"를 그래프로 보여줘요. 스피커 EQ 잡거나 방 음향 진단할 때 핵심 도구예요.

① 신호 발생기 (Signal Generator)

측정용 소리를 내보내는 부분이에요.

  • Pink / White / Sweep — 측정 신호 종류. Pink(핑크 노이즈)가 일반적인 음향 측정용 "쉬익~" 소리예요. Sweep는 저음→고음으로 훑는 신호.
  • File… — 직접 만든 음원 파일로 측정. 오디오 파일을 창에 끌어다 놓아도 바로 불러옵니다(WAV·FLAC·AIFF·MP3 등).
  • Level — 내보내는 소리 크기. − / + 로 조절.
  • Out — 어느 출력 채널로 내보낼지.
  • ▶ Play (G) — 신호 재생/정지.

② 기준(Reference)과 측정(Measurement)

  • Reference — "원본" 신호. 보통 Internal (SigGen)(방금 그 발생기 소리)로 둡니다.
  • Measurement — 마이크로 받은 "실제" 소리. Meas에서 마이크 장치/채널을 고르세요.
즉 SPECTRA가 원본(Reference) ↔ 마이크 소리(Measurement)를 비교해서 결과를 그립니다.

③ 딜레이(Delay) 맞추기 — 중요!

마이크가 스피커에서 떨어져 있으면 소리가 조금 늦게 도착해요. 이 시간차를 맞춰줘야 정확한 측정이 됩니다.

신호를 재생한 상태에서 Auto 버튼(L)을 누르면 — SPECTRA가 딜레이를 자동으로 찾아 맞춰줍니다. 끝!

④ 결과 그래프 3종

그래프무엇을 보나쉽게
Live IR
(임펄스 응답)		소리가 도착하는 모양/시점맨 위. 뾰족한 봉우리 = 소리가 도착한 순간. 딜레이 확인용.
Phase
(위상)		주파수별 타이밍 어긋남가운데. Wrapped/Unwrapped로 표시 방식 전환. 스피커 정렬·크로스오버 점검.
Magnitude + Coherence
(크기 + 신뢰도)		주파수별로 커졌나/작아졌나 + 그 측정이 믿을 만한가맨 아래. 곡선이 평평하면 "착색 없이 고르게" = 좋음. 코히어런스는 0~1, 1에 가까울수록 신뢰도 높음.
코히어런스(Coherence)가 뭐예요? — "이 측정값을 믿어도 되나"를 0~1로 나타낸 점수예요. 주변이 시끄럽거나 신호가 약하면 낮아집니다. 높은(1에 가까운) 구간의 결과만 신뢰하세요.

⑤ 그 외 컨트롤

  • FFT / Avg / Smooth — 분석 정밀도/평균/곡선 매끄럽기. Avg를 올리면 안정적, Smooth는 보기 좋게 다듬어요.
  • Find (L) — 딜레이 자동 찾기(위와 동일).
  • Capture — 현재 측정 곡선 저장(비교용).
  • △ (델타) — 저장한 곡선 대비 차이만 보기. EQ 전후 비교에 유용.
  • 측정 채널 추가 — 여러 지점을 동시에 측정/비교(각 색으로).

6Stereo Loudness 탭 — 스테레오 & 음량(LUFS)

좌우(L/R) 스테레오 상태와, 방송·음원에서 쓰는 "체감 음량"을 봅니다.

왼쪽 — 벡터스코프 (Vectorscope)

좌우 채널의 위상/이미지 관계를 동그란 그림으로 보여줘요.

  • 점들이 세로(위아래)로 모이면 — 좌우가 잘 맞는 좋은 스테레오.
  • 가로로 퍼지면 — 좌우 위상이 어긋남(모노로 합치면 소리가 깨질 수 있음).
  • 아래 상관도(+1 ~ −1) — +1=완벽히 같음(모노 안전), 0=넓은 스테레오, −1=위상 반전(주의).

오른쪽 — 라우드니스 레이더

시간에 따른 음량을 원형(레이더)으로 그려요. 방송 규격 맞출 때 핵심.

LUFS가 뭐예요? — 사람이 실제로 느끼는 "체감 음량" 단위예요. 단순 피크가 아니라 "전체적으로 얼마나 크게 들리나". 방송/스트리밍은 이 값으로 규격을 정합니다(예: 방송 −23 LUFS, 유튜브 −14 등).
지표뜻쉽게
M (Momentary)순간 음량(~0.4초)지금 이 순간 얼마나 큰가
S (Short-term)단기 음량(3초)최근 몇 초 평균
I / Program통합 음량(전체)제일 중요 — 처음부터 지금까지 전체 평균. 규격과 비교하는 값.
TP (True Peak)실제 최고 피크(dBTP)클리핑(찌그러짐) 위험 체크. 보통 −1dBTP 이하 권장.
LRA음량 범위(다이내믹)조용한 곳과 큰 곳의 차이. 클수록 다이내믹.
  • Target — 목표 음량(−23 LUFS 등) 설정. 레이더에 기준선으로 표시.
  • Reset I / Reset TP — 통합 음량 / 트루피크 측정을 초기화(새로 시작).
  • L · R — 좌/우로 쓸 입력 채널 지정.

7마이크 캘리브레이션 (정확한 소음 측정)

화면의 dBSPL 숫자를 실제와 똑같이 맞추는 작업입니다.

마이크마다 감도가 달라서, 보정을 안 하면 화면 숫자가 실제 소음과 다를 수 있어요. 캘리브레이터(기준기)가 있으면 정확히 맞출 수 있습니다.

헤더의 Calibration 버튼 클릭 → ① 마이크에 캘리브레이터를 끼우고 켜기 → ② 기준값(94 또는 114 dBSPL) 선택 → ③ 레벨 측정 → SPECTRA가 오프셋을 자동 계산해 맞춰줍니다.
다채널 인터페이스를 쓰면 채널마다 따로 보정할 수 있어요. 채널 목록에서 채널을 고른 뒤 각각 측정하면, 설정값이 채널별로 저장됩니다.
캘리브레이터가 없어도 SPECTRA는 잘 작동해요. 다만 dBSPL 절대값이 정확하지 않을 뿐, 주파수 분석·상대 비교는 문제없습니다.

8SPL Meter (큰 소음계 창)

멀리서도 보이는 큰 숫자 소음계를 별도 창으로 띄웁니다.

Spectrum 탭의 LEVEL 패널 우측 위 ↗ 아이콘을 누르면 열려요. 공연장에서 객석 소음을 모니터하거나, 측정값을 크게 띄워둘 때 좋아요.

  • 자유 배치 — 창 안의 ⚙️ 설정에서 행×열(1×1 ~ 4×4)을 정하고, 각 칸에 보여줄 지표(dB SPL A/C, LAeq, LCeq)를 고를 수 있어요.
  • Max 표시 — 각 칸에 최고값을 기록. ↺ 버튼으로 리셋.
  • LEQ 시간 — 평균을 낼 시간(1분~3시간) 설정.
  • 창 크기는 자유롭게 늘리거나 줄일 수 있고, 글자도 따라 커집니다.

11문제 해결

증상해결
그래프가 안 움직여요① 왼쪽 위 ▶ Start를 눌렀는지 ② 우측 INPUT에서 올바른 장치/채널을 골랐는지 확인.
장치(마이크)가 목록에 없어요케이블 연결 후, 장치 선택 콤보를 다시 열어보세요. USB는 뽑았다 끼우면 자동으로 다시 잡습니다.
USB 인터페이스를 뽑았더니 멈췄어요다시 꽂으면 자동 복구됩니다. 안 되면 장치를 다시 선택하세요.
소음(dBSPL) 숫자가 실제와 달라요마이크 캘리브레이션(7번)을 하세요.
Transfer Function 결과가 이상/불안정신호를 재생하고 Auto(딜레이)를 먼저 맞추세요. 코히어런스가 낮은 구간은 신뢰하지 마세요(주변 소음↓, 신호 레벨↑).
매그니튜드 곡선이 화면 밖(아래)에 있어요마이크 입력 레벨이 낮아서예요. 그래프를 더블클릭하면 자동으로 맞춰지고, 인터페이스에서 마이크 게인을 올리면 0dB 쪽으로 올라옵니다.
